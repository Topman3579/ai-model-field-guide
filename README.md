# เลือก AI ให้ตรงภารกิจ

React infographic แนวตั้ง 3:4 สำหรับเปรียบเทียบบทบาทเชิงใช้งานของ GPT, Claude,
Gemini, Kimi, GLM, DeepSeek และ Qwen

## หลักการของเนื้อหา

- เปรียบเทียบบทบาทและความเหมาะสมเชิงใช้งาน
- ไม่อ้างคะแนน benchmark, ราคา, context window หรือเลขรุ่นที่อาจเปลี่ยนแปลง
- เน้นการใช้หลายโมเดลร่วมกัน การตรวจสอบโดยมนุษย์ และการปกป้องข้อมูล

## เริ่มใช้งาน

```bash
npm install
npm run dev
```

## ตรวจ production build

```bash
npm run build
npm run preview
```
